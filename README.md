# TETRIS NEON 🎮

Phase 1~3까지 완성된 플레이 가능한 테트리스 웹 게임

## Features
- 10x20 보드, 7-Bag 랜덤
- SRS 회전 + 벽킥
- 고스트 피스, 홀드(C), NEXT 3개
- 소프트/하드 드랍, 점수/레벨/라인 시스템
- 모바일 터치 컨트롤
- 네온 레트로 디자인 + 효과음

## 조작법
- ← → : 이동
- ↑ / W : 회전
- ↓ : 소프트 드랍
- Space : 하드 드랍
- C / Shift : 홀드
- P : 일시정지

## 배포
이 레포는 단일 index.html 파일이라 GitHub Pages로 바로 배포 가능

### GitHub Pages로 배포하기
1. 이 레포를 그대로 GitHub에 push
2. Settings > Pages > Source: main / root
3. https://your-id.github.io/tetris-neon/ 에서 플레이

## Tech
- React + Tailwind (CDN) - 빌드 없이 동작하는 단일 HTML
